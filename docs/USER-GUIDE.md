# 使用指南

登录自己的 WordPress 管理后台，使用安装时创建的管理员账号。演示站点仅供公开浏览，不提供共享管理账号。服务器脚本安装者可在 root 专用的 `/etc/chenjin-blog/access.txt` 查看初始凭据，并及时修改密码；不要将该文件上传到仓库。

## 发布文章

1. 登录后进入「文章 → 写文章」。
2. 输入标题，使用区块编辑器添加正文、代码、图片和小标题。
3. 右侧设置分类、标签、特色图片和摘要。
4. 点击预览，再发布；可保存草稿或修改发布时间以定时发布。
5. 已发布文章可以重新编辑，修订记录可恢复旧内容。

文章页自动生成二级、三级标题目录，代码区块支持复制。中文搜索通过站点搜索框使用。文章和评论仍在 WordPress 后台管理，不因主题切换而迁移或删除。

## 修改首页与个人信息

- 首页展示公开项目和最近文章。
- 「设置 → 常规」：站点名称与副标题。
- 「设置 → 常规 → 网站备案号」：维护已经获批的网站备案号，页脚自动显示，留空则隐藏；此配置保存在数据库中。
- 「用户 → 个人资料」：显示名称和密码。
- 「页面」：编辑关于、隐私说明、项目页。项目页保留 `[ws_projects]` 即可自动展示。
- 站点 Logo 使用「外观 → 自定义」中的站点标识（`custom_logo`）。Muse 风格的金色、冰蓝、紫色银河背景、星尘流星、光晕卡片、三维太阳系、页头页脚和交互由 `chenjin-news` 子主题维护；Blocksy 的部分页头外观选项不控制子主题自定义页头。
- 「外观 → 菜单」：将 WordPress 菜单分配到 `menu_1` 主导航位置。

首页直接展示项目和文章，减少辅助文案；全站文章、分类、搜索和项目内容均来自 WordPress 与插件的真实数据。滚动渐显每次重新进入视口都会播放；支持手机导航、键盘操作与减少动态效果。

### 三维太阳系

首页太阳系由本地 Three.js WebGL 绘制，仅显示太阳和八大行星，没有月球。行星表面贴图由程序生成，并有太阳着色器、日冕 Bloom、地球云层与大气、土星环和银河旋臂。天体按固定演示速度自转、绕转；这是视觉演示，外侧行星绕转较慢。

拖动可旋转视角，滚轮或双指可缩放；点击天体聚焦，双击或按 Esc 返回总览。场景不显示控制按钮。浏览器标签页隐藏或 WebGL 上下文丢失时暂停渲染，页面恢复可见、获得焦点或从浏览器前进/后退缓存恢复时重新启动。无脚本时保留静态土星图片；WebGL 加载失败时显示页面状态提示。

这些固定速度仅用于视觉演示，不是实时星历、观测数据或真实物理周期。太阳与行星的半径、轨道距离经过压缩，不可据此判断真实尺寸或绝对距离。当前场景不读取仓库中保留的旧版 Solar System Scope 图片。

## 项目与资源

「设置 → GitHub 项目」显示公开仓库数量和同步时间，可手动同步。每小时自动同步，由系统每五分钟处理到期任务，无需有人打开网页。

资源来自 GitHub 公开 API。同步失败时保留最近成功的数据；下载入口直接指向原仓库。新建公开仓库后，下次同步会自动加入。

项目卡片只显示精简摘要，可展开原有详情，也可进入站内独立详情，例如 `/projects/?project=chenjin-blog`。独立详情只读取同步缓存中的合法公开仓库；源码、README、Release 和附件下载仍指向原仓库。仓库的许可证、默认分支、创建时间、代码更新时间、Fork 数和技术标签随同步更新。中文名称、功能摘要和使用步骤根据公开 README 整理，保存在插件的 `project-details.json`，页面标明核对日期；这些介绍不会自动随 README 更新，需要维护者核对后修改。新仓库没有整理摘要时仍显示仓库信息与 README/版本入口。

## 评论与媒体

「评论」中审核、回复或删除评论。默认所有访客评论需要审核；不会直接公开访客邮箱。无需开放访客账号注册。

「媒体 → 添加媒体」上传图片和文件，当前单文件上限 32MB。APK、发布包等较大资源保留 GitHub Releases 下载入口，避免占用博客服务器。

## 维护

WordPress 安全与小版本更新自动安装；核心大版本、`chenjin-news` 子主题与自定义插件需要备份后检查。Blocksy 父主题通过 WordPress 官方渠道自动更新，子主题由本仓库维护；第三方 SEO 和登录限制插件开启自动更新。升级前可运行服务器备份脚本。不要删除「陈今的 GitHub 项目」插件，否则项目短码会失效。

本站不使用个人邮箱、邮件通知或邮箱找回密码。管理员如需重置密码，请通过服务器 WP-CLI 操作，并将新密码保存在自己的密码管理器中。

## 站内联系

访客通过「联系」页留言，无需邮箱。管理员在后台「站内来信」查看、处理或删除留言。来信不进入公开文章、搜索、RSS 或 REST API。本站不配置个人邮箱。

## 构建三维场景脚本

主题加载随包提供的 `solar-system.min.js`，不依赖运行时 CDN。修改 `solar-system.js` 后，在仓库根目录执行：

```sh
npx --yes esbuild@0.28.2 wp-content/themes/chenjin-news/solar-system.js --bundle --format=esm --minify --legal-comments=linked --outfile=wp-content/themes/chenjin-news/solar-system.min.js
```

当前使用 Muse 源码随附的 `assets/vendor/muse-three.js`，文件内部标记 Three.js r186；保留 `assets/vendor/THREE-LICENSE.txt`。字体子集位于 `assets/fonts/`，保留同目录的 `OFL.txt`。
